### About Me

I'm a Computer Science student specializing in Machine Learning and Deep Learning. I like taking a project the full distance — not just training a model, but wrapping it in something that actually runs: a dashboard, a web app, an agent that reacts to its environment.

My work spans three areas: **reinforcement learning** (training agents to solve control problems), **computer vision** (building interactive tools around CV algorithms), and **applied deep learning** (churn prediction, credit risk, NLP). I'm comfortable across the stack — PyTorch and TensorFlow for modeling, scikit-learn and OpenCV for classical ML/CV, and Pandas/NumPy for the data work in between.

**[KAI — The Companion](https://github.com/RutujaKumbhar17/KAI-The-Companion)**
